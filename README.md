# DevKit Pro

Full developer toolkit with launch automation

## Overview
DevKit Pro is a downloadable macOS app bundle designed for indie hackers and software engineers who want to skip boilerplate configuration. It combines a robust CLI with complete source code access to automate local development environments and streamline the app launch process.

## Use cases
- Setting up a new development machine from scratch with a single command instead of manually installing dependencies
- Automating repetitive deployment and release workflows before pushing to production
- Inspecting, modifying, and extending the core source code to fit custom internal toolchains

## How to use
1. Download the app bundle and move it to your Applications folder
2. Run the built-in setup and doctor commands to configure your environment
3. Execute your first automated launch workflow via the CLI

## What is included
- Everything in DevKit CLI
- Setup and doctor commands
- Full source included
